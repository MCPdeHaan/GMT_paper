# GMT replication project

This repository supports *The Tax Base Decides: Why Global Minimum Tax Revenue Estimates Disagree*, using pinned public OECD CbCR for FY2017–2023. Start with [the manuscript](writing/paper_v2.tex), [replication guide](REPLICATION.md) and [architecture](docs/architecture/current_architecture.md). The numbered scripts in `code/` implement the frozen methods. Pinned input paths and hashes are in `tests/step17_raw_inputs.sha256`. `data/manual/` contains substantive anchors. Historical comparison fixtures live under `data/baseline_*/`.

- Inspect Git status before work. Preserve unrelated changes and user files. Use a fresh output directory for replay and keep the tracked raw, processed, golden and generated files intact during refactoring. Use the live collector only for a requested input-vintage change.
- Keep source liability, collector receipts and ordinary CIT distinct. State grain, keys, units, support, missingness and provenance close to each method. Prefer explicit function arguments and returns, checked joins and small modules. Put writes and seeds at clear stage boundaries. Keep modules safe to source, and retain compatibility for existing callers and saved models during migration.
- Use a lockfile-matched R library and documented system tools. From the root, check raw inputs with `shasum -a 256 -c tests/step17_raw_inputs.sha256`. Replay with `Rscript --vanilla run_all.R --output-root=/absolute/path`. Verify with `Rscript --vanilla tests/verify_golden_step15.R /absolute/path` and `GMT_TEST_OUTPUT_ROOT=/absolute/path Rscript --vanilla tests/testthat.R`. Test changed calculations rather than relying on their cached results. Compare generated TeX and compile the manuscript when changing publication code.
