## Comparison standard by output class

1. **Exact bytes.** On the pinned environment, preserve raw/manual, deterministic CSV and RDS, path sets and generated TeX for a parity change. For stochastic outputs the seed, input/draw ordering, inputs and code must be fixed. Verify the calculation or its correctly invalidated cache in addition to the bytes. PDF builds can compare exact content after excluding specifically identified volatile metadata and layout-neutral cross-reference offsets. On a different TeX stack compare pages, captions, cells, axes and visual layout.
2. **Numerical parity.** Use only where a deliberate schema/order/serializer/environment change makes byte checks inappropriate. Compare the full keyed data, factor levels, units, model terms/covariances, missingness, support flags and scenario coverage first. Compare rates with an absolute tolerance justified by the operation and inputs. The 08a matched nonlinear CSV replay uses `1e-7` in fractions to accommodate re-reading rounded inputs; that is not an across-the-board allowance for probabilities. For revenue follow the operation's existing checks and document absolute and scale-relative round-off. The sparse production parity currently requires US$0.001 per country-year-scenario; its large global sums use a machine-epsilon margin. For portability, retain original export/serialization tests alongside the keyed comparator.
3. **Preserved scientific estimands.** Audit the population, data vintage, weights, denominators, low-tax support, estimators and covariance, regime/time assumptions, interval definition and aggregation order. Use hand-worked edge cases and budget identities for quantities that must balance. A byte match establishes implementation preservation under the checked inputs. It cannot validate legal eligibility, causal interpretation, estimator support, statistical coverage or relevance of the chosen scenario distribution.

## Manuscript correspondence

The checked-in paper builds directly from the reproduced tables and figures. That connects current publication inputs to the exact empirical artefacts. TeX contains narrative values and legal claims written by hand, so builds and hashes do not independently validate every sentence. The [scientific issue register](scientific_issue_register.md) identifies known discrepancies and the controlled work needed for them. Important comparison units are source versus collector, cumulative USD versus annualised EUR, and model comparator versus observed receipts or statutory obligation.
